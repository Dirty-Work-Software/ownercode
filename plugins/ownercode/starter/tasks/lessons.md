# Lessons

Append one entry per owner correction. Grep by topic before non-trivial work. When a lesson recurs twice with `advisory: true`, write a hook or an AGENTS.md gate.

Format:

```
### YYYY-MM-DD
mistake: [what went wrong]
rule: [one sentence that prevents recurrence]
enforced-by: [hook/skill/doc]   (or `advisory: true`)
```
